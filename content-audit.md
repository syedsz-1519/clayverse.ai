## Key Audit Takeaways for Phase 1 & Phase 2

1. **Lesson Content Components** (e.g. `WhatIsAI.tsx`, `IndividualLessonView.tsx`, `GenerativeAI.tsx`, `PromptingAndRAG.tsx`, `AIFamilyTree.tsx`, `CheckYourKnowledge.tsx`, `ClosingAndDeeper.tsx`, `HomeCurriculumGrid.tsx`) contain extensive hardcoded English, Urdu/Hyd, and inline quiz/analogy definitions that must be decoupled into `src/content/lessons/<slug>/en.json`.
2. **Static UI Chrome Components** (e.g. `FloatingNav.tsx`, `GuideBreadcrumbNav.tsx`, `AuthModal.tsx`, `OfflineManagerModal.tsx`, `DailyLearningGoalTracker.tsx`, `SocialShareSection.tsx`) contain navigation headers, button triggers, and tooltips suited for `src/locales/<lang>/common.json`.
3. **Directional Styling**: Components containing chevron arrows (`ChevronRight`, `ArrowRight`, `ArrowLeft`), breadcrumbs, and status pills require CSS logical properties (`ms-*`, `me-*`, `rtl:rotate-180`) to ensure seamless Urdu RTL presentation.
